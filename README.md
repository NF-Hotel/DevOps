# NF Hotel DevOps

The authoritative repository for NF Hotel infrastructure and operations:
- CI/CD actions;
- deployment;
- PostgreSQL, backups, Tailscale, nginx and TLS;
- security, and their decisions and evidence.

The application lives in [NF-Hotel/NFHotel](https://github.com/NF-Hotel/NFHotel). The ownership boundary is ADR-0012 of NFHotel.

This first commit only creates the `main` branch. The content arrives through the migration pull request (MIL-025).
